# Shreyas R A - Personal Portfolio

A modern, dynamic personal portfolio website built to showcase my skills, projects, academics, and certificates. Designed with a focus on clean aesthetics, smooth interactions, and high performance.

## 🚀 Features

- **Modern & Minimal UI**: A sleek design that supports both **Dark** and **Light** themes.
- **Smooth Scrolling**: Enjoyable and fluid scrolling experience powered by [Lenis](https://lenis.studiofreight.com/).
- **Dynamic Animations**: Engaging micro-animations and page transitions using [Framer Motion](https://www.framer.com/motion/).
- **Interactive Elements**: Features an interactive, physics-based draggable ID card in the Hero section.
- **Fully Responsive**: Optimized for seamless viewing on desktops, tablets, and mobile devices.
- **Sections Included**: Hero, About, Skills, Projects, Academics, Certificates, and Contact.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) with [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: Framer Motion
- **Scroll Handling**: Lenis
- **Icons**: React Icons

## 💻 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Shreyas142004/My-portfolio.git
   ```

2. Navigate to the project directory:
   ```bash
   cd My-Portfolio
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and visit `http://localhost:5173/` (or the port specified by Vite).
